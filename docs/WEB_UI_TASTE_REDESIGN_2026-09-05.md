React/Vite 및 실제 제어 API를 유지하면서 화면 구성과 스타일을 교체했다.

## 디자인

- 고정 사이드바 대신 상단 내비게이션과 실제 현재 장치 이름을 배치했다.
- 스톤 배경, 포레스트 그린 버튼, 세이지 연결 영역으로 밝은 화면을 구성했다.
- Manrope와 Noto Sans KR을 로컬 자산으로 제공한다. 경로·공개 ID에는
  한국어 대체 글꼴이 포함된 IBM Plex Mono를 사용한다.
- 개요는 현재 서버와 실제 관리 폴더의 관계, 실제 완료 주기 전송량,
  폴더별 파일 수와 용량, 장치의 마지막 응답과 활동을 보여 준다.
- 로그인, 폴더·장치 양식, 상세 패널, 설정, 오류와 빈 화면을 같은 시각 체계로 맞췄다.
- 모바일 내비게이션과 모달의 키보드 동작, 포커스 복귀, reduced-motion을 지원한다.
- 활동 화면은 25개씩 표시하며 내보내기는 보존된 전체 기록을 포함한다.

장치 등록을 현재 온라인 상태로 해석하지 않는다. 그래프는 실제 완료 주기
전송량이며 변경 없는 주기는 0 B다. 로그인 일러스트는 폴더 동기화의 상징이다.
